# 片付けクエスト 仕様書 v0.1

現実の部屋を片付けるためのブラウザゲーム。片付けタスクを「クエスト」として登録し、こなすと経験値が貯まり、画面上の部屋がきれいになっていく。

## 1. 前提

- 利用者は自分ひとり。プロフィール切り替えは不要。
- 動作環境はスマホのブラウザを主とし、PCでも使える。
- サーバーなし。データはすべて `localStorage` に保存する。
- 素の HTML / CSS / JavaScript で作り、ビルド工程なし。GitHub Actions で `public/` だけを GitHub Pages に公開する。
- 見た目はやわらかい手描き風（パステル調、少しラフな線）。
- 設計方針: クエストをなるべく細かく分け、1つずつ片付ける（シングルタスク）ことを最優先にする。機能を足すときもこの方針に沿うかを基準に判断する。

## 2. 画面構成

単一ページで、下部タブで4画面を切り替える。タブの並びは クエスト、部屋、記録、設定。起動時は前回最後に見ていたタブを開く（初回はクエスト）。最後のタブは `localStorage` の `katazuke.lastTab` に保存し、エクスポートには含めない。

| タブ | 内容 |
| --- | --- |
| 部屋 | ホーム画面。エリアごとのカードを並べ、各カードの絵に散らかり具合が反映される。ヘッダー（全画面共通）は1行で、レベルと称号、経験値バー、ストリークを表示する。アプリ名は表示しない。 |
| クエスト | 先頭に「いまやる1つ」のカード（クエストごとのタイマー付き）、その下にタスク一覧（エリアで絞り込み可）。完了はタイマーを通してのみ行う（7章）。 |
| 記録 | カレンダー（月表示）、週間サマリー、セッションのランキング。 |
| 設定 | エリア編集、クエストの一括追加、データのエクスポート/インポート、初期化。 |

## 3. エリア

部屋を「エリア」に分割し、タスクはいずれかのエリアに属する。

- エリアは追加・名前変更・絵の種類の変更・並べ替え・削除ができる（設定画面）。並べ替えは ▲▼ ボタンで行う。
- 設定画面のエリア一覧には、絵のサムネイル（きれいの状態）、名前、所属クエスト数を表示する。絵の種類名は出さない（サムネイルで分かるため）。
- 初期エリア案: 机、床、ベッドまわり、クローゼット、キッチン、洗面所・風呂、玄関。
- 削除時は所属タスクをまとめて削除する（確認ダイアログあり）。

## 4. タスク（クエスト）

現実の片付け内容をユーザーが自由に登録する。

### 4.1 項目

| 項目 | 説明 |
| --- | --- |
| タイトル | 例「机の上の書類を仕分ける」 |
| エリア | 所属エリア |
| 難易度 | ★1 / ★2 / ★3。タイマーの長さは 3分 / 5分 / 10分（7章） |
| 繰り返し | なし / 毎日 / 毎週 / N日ごと |
| 期限 | 任意。繰り返しなしのタスクに「いつまでに」を付けられる。繰り返しありのタスクは完了時に自動で次回期限が入る |
| メモ | 任意 |

### 4.2 状態

- 繰り返しなしのタスクは、完了すると「達成済み」になり一覧から消える（記録には残る）。
- 繰り返しありのタスクは、完了後に次回期限が設定され、期限が来ると再び「やること」として表示される。
- 期限を過ぎたタスクは「期限切れ」として強調表示する。
- 繰り返しなしで期限も未設定のタスクは、常に「やること」として表示され、きれい度の計算では期限内として扱う。

### 4.3 いまやる1つ

一覧から選ぶ手間をなくし、1つずつ片付ける形にする。

- クエスト画面の先頭にエリアの絞り込みチップを横一列に置く。スマホでは画面の端まで使って横スクロールする。並びは「すべて」「エリアごと」のあとに各エリア。
- 「エリアごと」を選ぶと、「ほかのやること」をエリアの並び順で見出し付きに分けて表示する。各エリア内の並びは標準と同じ。「いまやる」と次のクエストも、この順（一番上のエリアから、エリア内は標準の並び）で決める。この選択は `katazuke.sections` に覚えておく。
- その下に「いまやる」カードを1枚だけ大きく表示し、残りは「ほかのやること」として折りたたむ。カードに「いまやる」のラベルや残り件数は出さない。コンボは2コンボ以上のときだけ、カードの右上に丸い札で出す。タイトルは札と重ならないように右側を空けて折り返す。
- 「ほかのやること」の並びは「いまやる」を決める規則と同じにし、上から順に次のクエストになる。
- 「いまやる」は次の順で自動的に決める: 期限日が早い順（繰り返しなしは任意の期限、繰り返しありは次回期限。期限なしは最後）、同じ日なら登録が早い順。当日スキップしたものは、その期限日の中で最後に回る（先送りが早い順）。難易度は並びに使わない。
- 完了すると次の1つが自動で出る（7章の流れに従う）。
- 「スキップ」ボタンで、同じ期限日のクエストの末尾に回せる（一覧には「スキップ済み」と出る）。同じ期限日を全部スキップした場合は、先送りが早かったものから順に戻ってくる。スキップは日付が変わると解除される。同じ期限日にほかのクエストがないときは押せない。タイマーが走っている間（一時停止中を含む）は押せない。
- 一覧の行には完了ボタンを置かない。完了は「いまやる」カードのタイマーからだけ行う（7章）。当日分の取り消しは従来どおり「今日やった」から行える。
- 「ほかのやること」「今日やった」「次回待ち」「達成済み」は折りたためる。初期状態はすべて閉じる。「ほかのやること」と「今日やった」の開閉状態は `localStorage` の `katazuke.sections` に覚えておき、次回も同じ状態で開く（エクスポートには含めない）。

### 4.4 一括追加（設定画面）

メモアプリや表計算ソフトに書き出した片付けリストをまとめて登録する。

- 設定画面の「クエストの一括追加」にテキストエリアを置き、1行1クエストで貼り付ける。
- 行の形式は `エリア：タイトル：期限：難易度：メモ`。区切りは全角「：」、半角「:」、タブのどれでもよく、1行の中で混ざってもよい（表計算ソフトから貼るとタブ区切りになる）。
- 項目の省略: 1項目だけならタイトル（エリアは「どこでも」）。2項目ならエリアとタイトル。3項目なら3つ目が難易度に見える（1〜3、★、☆）ときは難易度、そうでなければ期限。4項目以上ならエリア、タイトル、期限、難易度、メモの順で、5項目目以降はすべてメモとして「：」でつないで残す。空欄は飛ばせる（`机：書類を仕分ける：：2` は期限なしで難易度2、`キッチン：換気扇：：3：洗剤を買う` はメモ付き）。
- 行頭行末と区切り前後の空白（全角スペース含む）は取り除く。行頭の箇条書き記号（`-` `*` `・` `•` `□` `[ ]` `1.` など）は外す。空行は無視する。
- タイトルの中の「：」は区切りと見なされる。タイトルに「：」を含めたいときはタブ区切りで書く。
- エリア名が空、または区切りがない行は、エリア「どこでも」に登録する。「どこでも」がなければ絵の種類「家」で作る。
- エリア名が既存のエリア（前後の空白を除いて完全一致）にあればそこへ、なければ新しいエリアを作る。新しいエリアの絵は、一番上に並んでいるエリアと同じ種類。エリアが1つもないときは「棚」。新しいエリアは出てきた順に一番下へ追加する。
- 期限の書き方: `2026/9/20`、`9/20`（年なしは今日以降で直近のその日付）、`2026-09-20`、`9月20日`、`今日`、`明日`、`明後日`。期限はその日の 23:59:59 とする。
- 難易度の書き方: `1`〜`3`、`★`〜`★★★`、`☆`〜`☆☆☆`。省略時は 1。
- 繰り返しは指定できず「なし」。メモは200文字を超えたら切り詰める。
- タイトルが60文字を超える行は60文字に切り詰めて登録し、内訳に「切り詰め」として件数を出す。
- 読み飛ばす行: タイトルが空、期限が読めない、難易度が読めない、同じエリアに同じタイトルの未達成クエストがすでにある（貼り付けた中での重複も含む）。
- 「読み込む」を押すと、まず内訳（新規エリア、エリアごとの件数、切り詰めた行、読み飛ばした行とその理由）を表示し、「登録する」で確定する。
- 登録後は「N件を登録しました」と表示し、「取り消す」で今回追加したクエストとエリアをまとめて戻せる（次の操作をするまで有効）。
- 登録ボーナスは1件ごとに +1 XP を付ける（5.1のルールどおり）。演出は控えめ。

### 4.5 操作

- 追加、編集、削除、完了、完了の取り消し（当日分のみ）。
- タイマーのセッション中（7章の「待機」以外の状態）は、クエストの追加・編集・削除はできない。作業に集中させるため。行をタップしても編集シートは開かない。
- 完了時の演出とレベルアップの表示は、7章の「完了演出」モーダルで行う。クエストの追加・削除の登録ボーナスは小さな札だけの控えめな演出。
- OS の「視差効果を減らす」設定が有効なときは、紙吹雪などの動きを省く。

## 5. ゲームルール

### 5.1 経験値とレベル

以下の数値はすべて仮置き。実際に使いながら調整する。

| 難易度 | 経験値 |
| --- | --- |
| ★1 | 15 |
| ★2 | 25 |
| ★3 | 50 |

- 完了時の経験値 = 難易度の基本値 + タイマーボーナス（7章）。以前の「タイマー中は1.5倍」は廃止。
- 登録ボーナス: クエストを追加すると +1 XP、削除すると -1 XP（エリア削除でまとめて消える場合も1件ごと）。1日の上限はなし。減らすときは 0 未満にはしないが、レベルの境目をまたげばレベルは下がる（完了の取り消しと同じ扱い）。記録画面のカレンダーやストリークには数えない。演出は完了より控えめ（小さな札のみ、紙吹雪なし）。
- レベルアップに必要な経験値は `100 × 現在レベル`。累積ではなく、レベルごとにゲージがリセットされる。
- レベルに応じて称号を付ける。

| レベル | 称号 |
| --- | --- |
| 1 | 見習い |
| 3 | 片付け見習い |
| 5 | 片付け係 |
| 8 | 整理上手 |
| 10 | 整理の達人 |
| 15 | 片付けマスター |

### 5.2 ストリーク

- 1日に1つ以上タスクを完了すると、その日は「達成日」。
- 達成日が連続した日数をストリークとして表示する。
- 日付の切り替わりは端末のローカル時刻の 0時。
- 1日空くとストリークは 0 に戻る。救済措置は v0.1 では入れない。

### 5.3 部屋の散らかり具合

各エリアの「きれい度」を、所属タスクの状態から自動で決める。

- きれい度 = 期限内のタスク数 ÷ 有効なタスク数（繰り返しなしで達成済みのものは除外）。
- タスクが1つもないエリアは「きれい」扱い。
- 3段階に丸めて絵に反映する。

| きれい度 | 表示 |
| --- | --- |
| 80% 以上 | きれい |
| 40% 以上 | ふつう |
| 40% 未満 | 散らかり |

期限が過ぎるほど散らかっていくので、放置すると絵が自然に元に戻る（リバウンド）。

## 6. 部屋のビジュアル

- エリアごとに1枚のカードを表示し、カードの中にそのエリアの絵を描く。
- 絵はインライン SVG。エリアの種類ごとに 3 段階の絵（散らかり / ふつう / きれい）を用意し、きれい度で切り替える。
- 手描き風にするため、線は少し揺らし、塗りはパステル調。
- カードにはエリア名、きれい度、やることの件数（期限切れ・今日・期限なしの合計。次回待ちは含まない）を表示する。
- カードをタップすると、そのエリアのタスク一覧に移動する。
- エリアには「絵の種類」を設定する（机、床、ベッド、クローゼット、キッチン、洗面所、玄関、棚、家）。新しいエリアを作るときはこの中から選び、迷ったら「棚」を使う。「家」は家の外観で、場所を問わないクエストをまとめる「どこでも」エリア用。
- カードはエリアの並び順で、スマホでも PC でも3列に並べる。スマホでは文字と余白を小さくし、きれい度の点は省く。

## 7. クエストのタイマー

クエスト画面の「いまやる」カードにタイマーを組み込み、1つずつ時間を決めて片付ける。完了はこのタイマーを通してだけ行う。

### 7.1 タイマー

- 長さは難易度で決まる: ★1 = 180秒、★2 = 300秒、★3 = 600秒。
- 円の中に残り秒数を大きく整数で表示する（例: 287）。分秒表記や「秒」の文字は出さない。円の縁が残り時間に応じて減る（実行中は緑、一時停止は薄紫、時間切れは赤）。
- 数字の下には高さ固定の枠を置き、状態に応じて次を入れる（数字の位置は状態が変わっても動かない）: 待機中は ▶（スタート）、実行中は ⏸（一時停止）、一時停止中は ▶（再開）、時間切れは赤い「時間切れ」の札、次への待ちと休憩は空。アイコンは SVG で、ボタンは角の小さい四角に影を付けて札と区別する。
- ▶ / ⏸ / 時間切れの左に「−」、右に「+」を同じ大きさで置く。押すたびに10秒引く / 足す。表示は 0〜999 秒の範囲で、端に達したボタンは押せない。待機中はそのとき表示しているクエストの長さに効き、スキップなどで別のクエストに変わったら元に戻る。実行中・一時停止中・時間切れは今のタイマーに効く（時間切れからでも延長できる。0まで引くと時間切れになる）。増減した分もそのまま残り秒数として扱い、ボーナスの計算に含める。
- 円の下に主ボタンを大きく置く。待機中は「▶ スタート」、開始後は「☑ クエスト完了」（アイコンは SVG）。その下の中央に小さなボタンを置く。待機中は「スキップ」（同じ期限日の末尾に回す）。待機中はカードのボタン以外の場所をタップすると、いまやるクエストの編集シートが開く（一覧の行と同じ操作）。セッション中（実行中・一時停止中・次への待ち）は「× やめる」とその右に「スキップ」。セッション中のスキップは、いまのクエストを先送りして別のクエストで5秒の待ちに入る（走っていたタイマーは捨て、コンボは続く。ほかに候補がなければ押せない）。完了はスタートしたあとにしかできず、次への待ちの間は押せない。
- 残り秒数が0になったら音とバイブで知らせ、タイマーは0で止まる。「完了」は押せるがボーナスはない（コンボは続く）。
- 一時停止してもボーナスとコンボは続く（残り秒数は止まったまま）。
- 開始時刻と一時停止の累計を保存し、残り秒数は差分で計算する。画面を閉じても進む（現状のタイマーと同じ）。
- タイマーが走っている間（一時停止中を含む）は、ヘッダーに残り秒数を小さく表示する。

### 7.2 ボーナスとコンボ

- 時間切れになる前に完了すると、残り秒数 × 0.1 × コンボ倍率 を小数点以下切り上げしたボーナス経験値が付く。
- コンボは「セッション中に完了した回数」。時間切れの完了も数える。1コンボ目の倍率は 1.0、2コンボ目 1.2、3コンボ目 1.3、以降 0.1 ずつ増える（n コンボ目は 1 + 0.1 × n、ただし1コンボ目のみ 1.0）。上限なし。数列はあとで調整する前提。
- コンボは休憩、一時停止、時間切れをはさんでも続く。「やめる」でだけ0に戻る。
- 完了時の経験値 = 基本値（15 / 25 / 50）+ ボーナス。

### 7.3 セッションの流れ

最初に「スタート」を押してから「やめる」までを1セッションとする。状態は次のとおり。

| 状態 | 内容 |
| --- | --- |
| 待機 | タイマー未開始。「スタート」または円の中の ▶ を押すとセッションが始まり、「次への待ち」と同じ5秒のカウントダウン（音つき）を経てタイマーが動き出す |
| 実行中 | カウントダウン中。主ボタンは「クエスト完了」、円の中は ⏸ |
| 一時停止 | 円の中が ▶（再開）に変わる。「クエスト完了」も押せる（ボーナスとコンボは続く） |
| 完了演出 | 完了を押した瞬間に上昇する4音のチャイムを鳴らす。モーダルで経験値が足し上がるアニメーション（長さは行数で変わり、数字の動きが終わってから 2.1秒後に自動的に閉じる（基本のみ 3.4秒、ボーナスあり 4.3秒、コンボあり 5.2秒）。最後のクエスト（次がないとき）はさらに 1秒長い）。カードが弾んで紙吹雪が飛び、基本値 → ボーナス → コンボの行が順に現れて数字がカウントアップする。合計は「+」を小さく数値を大きく出し、カウントアップの段階ごとに拡縮して弾み、チャリンという音を鳴らす。最後にコンボの札ともう一度紙吹雪。レベルアップもここで見せる。終わると自動で閉じる |
| 休憩 | セッション開始（または前の休憩終了）から25分を超えていたら、完了演出のあとに5分の休憩に入る。モーダルで青いリングと残り秒数、「🔥Nコンボ 継続中」を表示し、操作は「休憩を終える」だけ。終わると音で知らせる |
| 次への待ち | 専用のカードで、タイトルを大きく中央に出し、その下の行にタイマーの長さを「（180秒）」のように少し小さく出す。その下にエリア・難易度・繰り返し・期限（例「机 · ★ · 毎日 · 1日遅れ」）を小さく、その下に5秒のカウントダウンの数字を大きく出す。リング、完了ボタン、コンボの札は出さない。カードの高さは開始時のカードと必ず同じにする（開始時と同じ構造を透明な下敷きにして、その上に重ねる）。文字は縦の中央、「× やめる」「スキップ」は下端に寄せる。数字は変わるたびに手前からふわっと縮小しながら現れる。残り3・2・1秒で短い低い音を鳴らし、0で長い高い音とともに自動でスタートする（カーレースのスタートのように）。即スタートの操作はない。「スキップ」で次のクエストを差し替えられる（5秒は数え直し） |
| まとめ | キラリンという上昇音とともに、セッションの結果（獲得経験値を大きく、達成数、最大コンボ、経過時間、ランキング順位）をモーダルで表示し、待機に戻る。上位5件に入ったら「自己ベストN位！」を出す |

- 「やめる」はセッション中いつでも押せる小さなボタン。確認ダイアログのあと、タイマーを止めてまとめを表示する。走っていたクエストは未完了のまま残る。
- やることがなくなったら、完了演出のあとにまとめを表示してセッションを終える。
- 最後の操作から30分以上経ってアプリを開いたときは、セッションを自動で終えてまとめを表示する（実行中だったクエストは未完了のまま）。
- 休憩は「25分を超えた最初の完了の直後」に入る。走っているクエストは中断しない。休憩が終わったら25分の計測をやり直す。
- 待機中の「スキップ」は順番を変えるだけ。セッション中の「スキップ」は、いまのクエストを先送りして次に進む。
- アプリを閉じている間は処理が動かないため、5秒のカウントダウンや休憩の終了は、次に開いたときに時刻から逆算して反映する。通知は出さない。

### 7.4 記録

- ログに基本値、ボーナス、コンボ数、タイマーの長さ、残り秒数を残す。記録画面の一覧に「+37（3コンボ）」のように出す。
- セッションの結果を履歴に残し、記録画面に獲得経験値の上位5件をランキングとして表示する（日付、経験値、達成数、最大コンボ）。

## 8. 記録

- 上部に集計カード: 連続日数、最長連続、達成数の合計、獲得経験値の合計。
- 月カレンダー。達成日はマスに色を付け、完了数に応じて濃くする（1件 / 2〜3件 / 4〜5件 / 6件以上の4段階）。前後の月に移動でき、「今日」ボタンで戻る。
- カレンダーの日をタップすると、その日に達成したクエストの一覧（時刻、タイトル、エリア、経験値とそのうちのボーナス、コンボ数）を表示する。初期選択は今日。
- 週間サマリー: 今週（月曜始まり）の完了数、獲得経験値、活動日数、エリア別の完了数（横棒）。
- セッションのランキング: 獲得経験値の上位5件。日付、経験値、達成数、最大コンボを並べる。
- 削除されたクエストの記録は「（削除されたクエスト）」として残す。

```json
    { "startedAt": "2026-09-09T21:00:00+09:00", "endedAt": "2026-09-09T21:40:00+09:00", "completed": 6, "xp": 143, "maxCombo": 4 }

```

- `version` はアプリが 0.x の間は 1 のまま上げない。使っているのが自分だけなので変換処理は書かず、読み込み時に足りない項目は初期値で埋め、知らない項目（旧 `timer` など）は無視する。1.0 以降に形を変えるときから番号を上げて変換処理を書く。
- `session.phase` は `idle` / `running` / `paused` / `done` / `break` / `countdown` / `summary`。`phaseStartedAt` はその状態に入った時刻で、完了演出・休憩・5秒カウントダウンの経過はここから計算する。
- `logs[].xp` は基本値とボーナスの合計。`combo` はその完了が何コンボ目か（0 はボーナスなし）。

- `player.xp` は累計経験値。`player.level` は保存時に `xp` から計算して入れる（表示用。読み込み時は `xp` を正とする）。
- `sample` は初回起動のサンプルデータが入ったままかどうか。設定画面の「サンプルを消す」ボタンの表示に使う。

- `repeat.type` は `none` / `daily` / `weekly` / `days`。
- `deadline` は繰り返しなしのタスクに任意で付ける期限。`dueAt` は繰り返しタスクの次回期限で、どちらも未設定なら `null`。
- `deferredAt` は「あとで」を押した時刻。日付が今日のときだけ有効。
- `logs[].prev` は完了前のタスク状態。当日中の取り消しで元に戻すために使う。
- 繰り返しタスクの次回期限は、完了日の翌日（毎週なら7日後、N日ごとならN日後）の 0:00 にそろえる。
- 任意の期限（`deadline`）はその日の 23:59:59 とする。
- `areas[].kind` は絵の種類。`desk` / `floor` / `bed` / `closet` / `kitchen` / `bath` / `entrance` / `shelf` / `house`。
- 日付は ISO 8601 文字列で保存する。

### 9.3 エクスポート / インポート

- エクスポート: JSON をテキストエリアに表示してコピーできるようにする。ファイルダウンロードも用意する。
- インポート: JSON を貼り付けるか、ファイルを選択して読み込む。読み込み前に現在のデータを上書きしてよいか確認する。
- `version` が異なる場合は変換処理を通す（1.0 以降）。0.x の間は足りない項目を初期値で埋めるだけにする。

### 9.4 初期化

設定画面から全データを削除できる。二重確認する。削除後はエリアも含めて何もない状態になる（サンプルは入れない）。エリアは設定画面から追加するか、一括追加で自動的に作られる。

## 10. 初回起動

- サンプルのエリアとタスクを数件入れた状態で始める。
- 「サンプルを消して自分で登録する」ボタンを設定画面に用意する。押すとクエスト、記録、レベルを消し、エリアは残す。

## 11. 非機能

- スマホ縦画面を基準に設計し、PC では中央寄せの幅固定で表示する。
- オフラインでも開けるよう、外部ライブラリは使わない。フォントは Google Fonts の丸ゴシック（Zen Maru Gothic）を1つだけ使い、読めないときはシステムの丸ゴシックにフォールバックする。
- 外部への通信はしない。
- 確認ダイアログは OS の `confirm` / `alert` を使わず、アプリの見た目に合わせた独自のモーダル（`dialog.js`）で出す。危険な操作の主ボタンは赤にし、外側のタップや Esc でキャンセル、Enter で決定。
- アイコンは絵文字を使わず、`index.html` に置いた SVG のシンボル集を `<use>` で参照する。線は文字色（`currentColor`）、塗りは CSS 変数で変える。絵文字は端末ごとに形と大きさが違い、タブバーの高さがぶれる原因になったため。
- PWA として動く。マニフェストとサービスワーカーを持ち、ホーム画面に追加すると全画面で開ける。アプリ本体はキャッシュしてオフラインでも開けるようにし、フォントはキャッシュがあればそれを使う。
- 新しい版が配信されたら「新しい版があります」の帯を出し、「更新する」で切り替える。設定画面に版の表示と「更新を確認」ボタンを置く。
- 公開先は `https://ariek.github.io/katazuke/` のようなサブパスなので、マニフェストとサービスワーカーのパスは相対で書く。
- iOS のステータスバー（時計の帯）は `default` にして iOS に描かせる。透過（`black-translucent`）は余白の値が 0 で返る不具合があり、ヘッダーが時計と重なるため使わない。帯の分だけ上が空くのは iOS の仕様として受け入れる。
- iOS は `apple-mobile-web-app-*` のメタ情報をホーム画面に追加した時点で固定するため、それらを変えたときはアイコンを削除して追加し直す必要がある。
- ページ全体は固定し、本文だけをスクロールさせる。ヘッダーとタブバーは慣性スクロールで動かない。
- 全画面（ホーム画面から起動）のときはタブバーを低くし、下の余白はホームインジケーターと重ならない最小限にする。余白の値は JS で実測して CSS に渡す（iOS で `env()` を含む計算が効かないため）。

## 14. 検討事項（未実装）

単一タスクで進めやすくするための案。「いまやる1つ」を使ってみてから判断する。

- **今日の順番を手動で決める** … 「やること」の中で ▲▼ やドラッグで順番を変える。全体の並べ替えより、朝に3つほど選んで並べる「今日のクエスト」欄の方が軽い。
- **クエストの分割支援** … 追加・編集シートに「分割」ボタンを付け、1つのクエストを複数の小さなクエストに変換する。★3を登録しようとしたら「5分単位に分けますか？」と促す。チェックリスト方式は小項目に経験値が付かず達成感が薄いので、独立した小さなクエストに分ける方針。
- **「次の1つを引く」演出** … カードをめくるように次の1つが出る。少しランダム性を入れて飽きにくくする。
